**How to use:** paste this whole file into a fresh session, or reference it as

unedited. Everything below the line is the prompt.

## Task

Restyle `hackathon/demo/trailhead-demo.html` so it reads as a Goldman Sachs
institutional application rather than a field-survey / terminal-ledger artifact.

This is a **presentation-layer change only**. The information architecture, the
copy, the block types, and the embedded data are all correct and stay exactly as
they are. You are changing how it looks, not what it says.

The current file is 65 KB, self-contained, and passes both gate checks. It must
still do all three when you are finished.

## Before you touch anything: the refresh protocol

**This file is machine-regenerated.** `node tools/inline-fixture.js` rewrites the
`const D = { … };` block in place from `fixtures/verified.sample.json`, and stage
5 (RENDER) will eventually regenerate the whole shell. A copy of this file in
your context is stale the moment either runs.

Non-negotiable working rules:

1. **Re-read the file with the Read tool immediately before every edit batch.**
   Not once at the start — before *each* batch.
2. **Never use Write on this file.** Only `Edit`, against text you have just
   read. A full-file rewrite from memory will silently drop payload bytes.
3. **Work in small batches** — one component or one token group at a time, then
   re-read, then the next. Do not queue up twelve edits against one stale read.
4. **Check for drift around every batch.** Record the hash before you edit and
   confirm it is unchanged when you come back:

   ```powershell
   (Get-FileHash hackathon\demo\trailhead-demo.html -Algorithm SHA256).Hash
   ```

   If it changed underneath you, re-read and redo the batch — do not reapply.
5. **Optional watcher**, if you want a live signal that someone else regenerated
   the bundle (run in the background, PowerShell):

   ```powershell
   $f = "hackathon\demo\trailhead-demo.html"; $last = ""
   while ($true) {
     $h = (Get-FileHash $f -Algorithm SHA256).Hash
     if ($h -ne $last) { "$(Get-Date -f HH:mm:ss)  changed  $($h.Substring(0,12))"; $last = $h }
     Start-Sleep 2
   }
   ```
6. **After every batch**, run both gate checks (below) and hard-reload the page
   in the browser (`Ctrl+Shift+R` — a normal reload will serve you the cached
   `file://` copy and you will review your own stale work).

**Do not add a live-reload or `<meta http-equiv="refresh">` to the bundle.**
Non-negotiable #5 of the project is one HTML file with zero external requests and
no dev cruft. If you want browser auto-refresh, make an untracked dev-only copy
at `demo/.dev-preview.html`, never commit it, and never let it near the gate.

## The research: how GS actually builds UI

### Identity

- Goldman Sachs refreshed its identity in **August 2024**: the historic **GS
  ligature** was restored, a horizontal **GS monogram** added, the wordmark went
  from blue-and-white to **black**, and the blue box was dropped as a separate
  element. The stated intent is *reliability and consistency*, expressed through
  typography rather than decoration.
- Two proprietary typefaces came with it: **GS Serif** for headlines and short
  text blocks, and **GS Sans** (plus **GS Sans Condensed**) for body text,
  replacing Basis Grotesque. **Goldman Sans** — the 2020 Dalton Maag face,
  criticised at the time as insufficiently distinctive — was retained.
- Goldman Sans was designed to be *clear, contemporary, credible*; "approachable
  without being whimsical", "neutral, with a wink". Open apertures, **enlarged
  x-height**, optically balanced letterforms, chamfered spurs on `p q n g` for
  white space, and **numerals drawn to align in spreadsheets across weights**.
- **Sky Blue** remains the primary brand colour and has for decades.

### Design system

- The **GS Design System** launched February 2020 under the OneGS initiative,
  defining visual styles, interaction patterns and UX guidelines firm-wide.
- The **UI Toolkit** is 60+ plug-and-play JavaScript components (`@gs-ux-uitoolkit-react/*`
  on npm) with CSS-in-JS styling, cross-browser/mobile support, and accessibility
  built in. Foundation kit = colour, type, iconography, **design tokens**;
  component kit = buttons, badges, accordions, checkboxes, charts.
- Both **light and dark** are first-class — Marcus built every component in both.
- **Marquee**, the institutional client platform, was one of the first adopters:
  data-dense, function-first screens.
- Stated principles: *start with users · clarify complexity · deliver value, not
  features · empower clients · consistency, at scale*. "Form follows function" —
  **clarity over shininess**.
- Colour carries meaning in a defined hierarchy: **action level** (primary,
  secondary) and **workflow status** (info, success, warning, danger), separate
  from decorative palette hues.
- They published research on **building accessible colour palettes**, broken out
  by use case — data visualisation, functional/status colours, dark and light
  variants — plus keyboard navigation, iconography, elevation (drop shadows),
  and tooltip/message writing guidelines.
- The public site (`design.gs.com`) was withdrawn in mid-2024 and now redirects
  to the corporate site, so treat the above as the reliable public record and do
  not invent token names that claim to be theirs.

### What that means for this page

The current aesthetic is deliberate and coherent — warm bone-on-black, contour
grid, film grain, olive-green accent, monospace everywhere, humanist serif
display. It reads as a *field survey document*. GS reads as an **institutional
finance workstation**: cool navy-slate neutrals, sky blue as the single
interactive accent, sans-serif for interface text with monospace confined to
code and figures, restrained elevation, and semantic status colour that is never
doing brand duty at the same time.

The single most important structural change: **the current `--ok` green is both
the brand accent and the "verified" status colour.** GS separates action
hierarchy from workflow status. Split them — sky blue becomes the interactive
accent, green stays and means only *verified*.

## Direction

### 1. Tokens

Replace the `:root` blocks. This ramp is a **starting point, not a spec** — you
must verify every text/background pair clears **4.5:1 in both themes**
(acceptance test 10) and adjust the values that don't. Report any you moved.

```css
:root{
  /* surfaces — cool navy-slate, not warm black */
  --ink:#0A0E14; --ink2:#111722; --ink3:#18202D; --ink4:#212B3A;
  /* text */
  --bone:#E8ECF2; --dim:#9BA8BA; --faint:#6B7B90;
  /* structure */
  --rule:#1E2735; --rule2:#2C3849;
  /* brand / interactive — GS sky blue */
  --brand:#7399C6; --brand2:#ACD4F1; --brandd:#12243A;
  /* workflow status — verified / inferred / broken */
  --ok:#4FA97A; --inf:#D8A23C; --bad:#E06C5B;
  --okd:#0F2A20; --infd:#2A2210; --badd:#2E1614;
}
:root[data-theme="light"]{
  --ink:#FFFFFF; --ink2:#F5F7FA; --ink3:#EAEEF4; --ink4:#DDE4ED;
  --bone:#14181F; --dim:#4A5464; --faint:#6E7A8A;
  --rule:#E1E6EE; --rule2:#C9D2DE;
  --brand:#00355F; --brand2:#2178C4; --brandd:#E8F1FA;
  --ok:#1F7A4D; --inf:#8A5C10; --bad:#B3261E;
  --okd:#E4F2EA; --infd:#FBF0DA; --badd:#FBE9E7;
}
```

Note the asymmetry and keep it: **sky blue `#7399C6` is the dark-theme
interactive colour; on white it fails 4.5:1 as text**, so light theme drops to
deep navy `#00355F` with Mariner `#2178C4` for hover/links. Getting this right
in both directions is the whole point of GS's accessible-palette work.

Published GS brand values you can draw from: `#7399C6` sky blue, `#00355F` deep
navy, `#ACD4F1` pale blue, `#231F20` near-black, `#58575A` grey, `#FFFFFF`,
`#22263F` Ebony Clay, `#2178C4` Mariner.

Add, and then actually use:

```css
--r1:2px;   /* controls, pills, inputs */
--r2:4px;   /* cards, panels, drawer, modal */
--e1:0 1px 2px rgba(4,8,14,.28);      /* raised surface */
--e2:0 8px 24px rgba(4,8,14,.40);     /* overlays only: drawer, modal, popovers */
```

Nothing rounder than 4px. GS is square-ish and sober, not friendly.

### 2. Typography

`@font-face` is banned by the gate, so **Goldman Sans cannot ship in this file.**
Do not try to base64 it in — the check greps for the at-rule. Approximate it with
a system stack and say so in a CSS comment.

> The grep is a plain string match over the whole file, so it fires on the
> at-rule's name appearing **anywhere — including inside a CSS comment.** Write
> the comment as "embedded font at-rules are barred", not with the literal token.

```css
--sans:-apple-system,BlinkMacSystemFont,"Segoe UI Variable Text","Segoe UI",
       Inter,Roboto,"Helvetica Neue",Arial,sans-serif;   /* ≈ Goldman Sans / GS Sans */
--serif:"Charter","Bitstream Charter","Sitka Text",Cambria,
        "Times New Roman",Times,serif;                    /* ≈ GS Serif */
--mono:"Cascadia Code","JetBrains Mono","SF Mono","IBM Plex Mono",ui-monospace,monospace;
```

Rules:

- **`body` switches from `--mono` to `--sans`.** This is the biggest single
  change in the file. Monospace is then confined to: code excerpts (`.code`),
  command strings (`.cmd code`, `.out pre`), claim marker ids (`.mark`), file
  paths, and figures.
- **Keep serif headings.** GS Serif for headlines is genuinely their pattern —
  `h1`, `.drawer h4`, `.cpx h4`, `.modal h3` stay serif. Drop `h1 em`'s green
  italic; use `--brand` or just leave it in `--bone`.
- **Tabular numerals everywhere a number appears**: badge counts, `.sumgrid .v`,
  `.dur`, LOC and churn columns, `.code .ln`, `#ppct`. Use
  `font-variant-numeric:tabular-nums` — this is a documented Goldman Sans design
  goal and it is what makes a financial UI look right.
- **Kill the tracking-heavy micro-labels.** The `9.5px` mono at `.2em` on
  `.track h3`, `.cpx>.k`, `.call b`, `.drawer h5`, `.tbl th`, `.plate` reads as
  a survey plate. Replace with `11px --sans`, `600`, uppercase, `.06em`,
  `--faint`. Legible small caps, not stencil.
- Body 16px / 1.6, prose column 72ch — spec §7, already correct, do not regress.

### 3. Delete the costume

These exist to sell "field survey" and are actively wrong for GS:

- `body::before` — the 47/48px contour graph-paper grid and the olive radial
  glow. Remove entirely. GS backgrounds are flat.
- `body::after` — the SVG `feTurbulence` film grain. Remove. Also saves bytes.
- `.sprocket` — the film-sprocket progress strip. Replace with a plain 4px track
  and `--brand` fill, percentage in tabular numerals beside it.
- `.brk` — the 135° hazard-stripe background on broken commands. Replace with a
  flat `--badd` surface, a 2px `--bad` left border, and the existing `BROKEN`
  label. Status by label plus colour, never stripes.
- `::selection{background:var(--ok)}` → `--brand`.
- The staggered `rise` entrance on `.blocks>*` — 500ms with six nth-child delays.
  Cut it, or reduce to a single ≤150ms opacity fade with no stagger.

Keep the `✓` tick on completed stops (`.stop.done .num::after`) — that is
meaning, not decoration. Restyle it, don't remove it.

### 4. Spacing and density

Current padding values are ad hoc — 7, 9, 11, 13, 19, 21, 22px. Snap everything
to a **4px scale**: 4 · 8 · 12 · 16 · 24 · 32 · 48. GS institutional screens are
dense but *regular*; the irregularity is what currently reads as hand-made.

Keep the density — do not let this become an airy marketing page. Rows stay
tight, the rail stays compact.

# Feature Notes

One file per feature family. Each file fills up as we explore the data hands-on.

Start empty. Add findings, plots, numbers, and code snippets as we discover them.

## Files

- `har-components.md` -- daily/weekly/monthly RV lags, the HAR baseline
- `jump-detection.md` -- BPV, threshold methods, continuous vs jump components
- `leverage-effect.md` -- return-vol asymmetry, signed semivariances
- `microstructure.md` -- noise, spread, LOB features, sampling frequency effects
- `cross-asset.md` -- spillovers, correlations, sector structure
- `implied-vol.md` -- VIX, IV surface, variance risk premium

# TypeScript Project Setup

Node.js via devtools. `devtools install nodejs`.

## Running

- Windows: `cmd /c "H:\javascript-env.cmd && node script.js"` (not on PATH)
- Linux: `node`/`npm` on PATH via `.bashrc`

## New Project

```bash
mkdir my-proj && cd my-proj
npm init -y
npm install typescript @types/node --save-dev
npx tsc --init
```

## tsconfig.json

```json
{"compilerOptions": {"target": "ESNext", "module": "NodeNext", "moduleResolution": "NodeNext", "outDir": "dist", "rootDir": "src", "strict": true, "esModuleInterop": true, "skipLibCheck": true, "sourceMap": true}, "include": ["src"]}
```

## package.json scripts

```json
{"build": "tsc", "start": "node dist/main.js", "dev": "tsc --watch"}
```

Entry point: `src/main.ts`.

## Build and Run

```bash
npm run build    # Compile
npm start        # Run
```

## Dependencies

```bash
npm install express                    # Runtime dependency
npm install @types/express --save-dev  # Types for it
```

## Directory Structure

```txt
my-project/
├── package.json
├── package-lock.json
├── tsconfig.json
├── src/
│   └── main.ts
├── dist/              (generated by tsc)
│   └── main.js
└── node_modules/
```

## Quick Reference

| What                 | Command                            |
| -------------------- | ---------------------------------- |
| Install Node.js      | `devtools install nodejs`          |
| Install dependencies | `npm ci`                           |
| Add a dependency     | `npm install <package>`            |
| Add a dev dependency | `npm install <package> --save-dev` |
| Build                | `npm run build`                    |
| Run                  | `npm start`                        |
| Watch mode           | `npm run dev`                      |
